# 퀴즈 맞추기 결과창 이미지 출처

`Assets/Resources/QuizResultImages/` 에 넣은 정답 유적 사진의 출처입니다.
파일 이름은 `SilueteGameManager` 의 정답 이름과 같아야 하며, 스크립트가 `Resources.Load<Sprite>` 로 불러옵니다.
사진이 이미 있는 16곳(`Assets/Prefabs/SilueteGameImages/`)은 기존 이미지를 그대로 쓰므로 여기에 없습니다.
